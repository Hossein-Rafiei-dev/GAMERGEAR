# 🎮 GAMERGEAR

### A Gaming Accessories Store Built with Next.js

GAMERGEAR is a gaming accessories e-commerce project focused on building a modern shopping experience with responsive UI components and reusable React architecture.

## 🚀 Features

- 🛍️ Product listing and product detail pages
- 🔎 Product search
- 📂 Category-based product browsing
- 🛒 Shopping cart functionality
- 📦 Checkout and order form interface
- 📱 Responsive user interface
- 🧩 Reusable React components

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **JavaScript**
- **Tailwind CSS**
- **JSON Server** for local development data
- **Git & GitHub**

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Hossein-rafiee-esf/GAMERGEAR.git
   ```

2. Open the project directory:

   ```bash
   cd GAMERGEAR
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

**Note:** The complete shopping experience currently depends on local development data served through JSON Server. A sanitized sample database and its setup instructions will be added separately.
